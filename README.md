# Sahavas-
Sahavas is a full-stack roommate finder and shared housing platform that connects room seekers with room owners directly. It offers lifestyle-based compatibility matching, room listings, advanced search and filters, interest requests, and direct communication. The platform aims to simplify the process of finding affordable, comfortable, and compatible shared accommodation through a secure, user-friendly, and broker-free experience. It also helps users make better housing decisions based on their preferences, budget, location, and lifestyle.
